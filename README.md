# 商道杯决策顾问 (Shangdao Decision Advisor)

一个面向 OpenAI Codex 的 AI Skill，用于辅助 **2026 年"商道杯"管理决策模拟挑战赛** 的年度决策制定。

AI 代理通过浏览器读取比赛界面（需求曲线、决策页面、历史成绩），自动生成涵盖生产、营销、财务、明星代言、股票投资等维度的年度决策方案。

## 项目结构

```
shangdao-decision-advisor/
├── README.md                        # 项目说明
├── SKILL.md                         # Skill 主定义：工作流、规则、安全策略、输出规范
├── agents/
│   └── openai.yaml                  # OpenAI 代理接口配置
├── references/
│   ├── data-collection.md           # 比赛数据采集指南（从 Web UI 提取数据）
│   ├── decision-heuristics.md       # 决策启发式策略（需求、生产、定价、财务等）
│   ├── manual-rules.md              # 学生手册权威规则（评分、需求、生产、财务等）
│   └── output-format.md             # 年度决策建议的结构化输出格式
└── scripts/
    └── analyze_snapshot.py          # 决策快照校验脚本（Python 3）
```

## 核心功能

### 1. 需求曲线分析
读取六大区域需求曲线（长三角、环渤海、珠三角、中西部、自有品牌、全国总量），自动判断需求所处阶段（增长期、高峰期、平台期、衰退期）。

### 2. 数据采集工作流
引导 AI 代理逐步导航比赛 Web 界面的三个核心页面：
- **查看比赛** — 获取当前赛况和历史数据
- **比赛决策** — 读取各决策标签页的当前设置
- **比赛成绩** — 分析往期得分与排名

### 3. 决策推荐引擎
生成覆盖 10 个决策标签页的结构化方案：
| 标签页 | 内容 |
|--------|------|
| 年度预算 | 整体资金规划 |
| 生产运营 | 产能、材料、人工配置 |
| 工厂建设 | 扩产/建厂决策 |
| 产品配送 | 区域配送比例分配 |
| 自由市场 | 线下渠道定价与营销 |
| 线上市场 | 电商渠道策略（上限 20%） |
| 自有品牌 | 代工投标策略 |
| 明星签约 | 代言人竞标方案 |
| 财务管理 | 融资、分红、回购策略 |
| 股票投资 | 股市投资决策 |

### 4. 手册规则引擎
将学生手册中的完整规则编码为约束条件，包括：
- 评分公式与战略分要求
- 11 项市场份额影响因素
- 质量/材料/产能/人工规则
- 财务硬限制（发股、回购、分红、债券评级）

### 5. 快照校验脚本
独立的 Python 3 脚本，对决策快照 JSON 进行确定性校验：
- 需求阶段分类
- 区域优先级排名（60% 当前需求 + 40% 来年增长）
- 现金/利润/ROI 负值预警
- 产能失衡检测
- 手册规则合规检查

### 6. 浏览器安全策略
默认禁止破坏性操作（删除、登出、保存、上传、提交），需用户确认后方可执行。

## 使用方式

### 作为 AI Skill 使用

将 `SKILL.md` 加载到兼容 OpenAI Codex 的代理平台中。`agents/openai.yaml` 提供接口配置。

### 运行校验脚本

```bash
python scripts/analyze_snapshot.py <snapshot.json>
```

- 输入：符合脚本文档中定义的 schema 的 JSON 文件
- 输出：JSON 格式的分析结果（输出到 stdout）
- 依赖：Python 3.9+，无第三方依赖
